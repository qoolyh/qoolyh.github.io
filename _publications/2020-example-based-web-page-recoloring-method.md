In this paper, we propose an example-based web page recoloring method which reuses an example’s colors to recolor the user’s web page. A heuristic clustering method is proposed to ensure the semantic-related elements will have the same recoloring strategy. And we propose a top-down matching algorithm to make the recoloring web page has similar color distributions to the example. The experiment results showed that both the methods achieved similar accuracies to humans’ results
